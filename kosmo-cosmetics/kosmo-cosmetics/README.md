# Косметика для Minecraft (Fabric 1.21.4)

Клиентский мод. Правый Shift открывает меню косметики, выбор сохраняется.

- **Голова:** рога, кошачьи уши, корона, нимб, цилиндр
- **Спина:** красный плащ, крылья ангела, крылья демона, рюкзак, кошачий хвост
- **Плечи:** наплечники, попугай, слайм, дракончик, эполеты
- **Меч:** тактический нож, изогнутый нож, катана, огненный клинок, энергетический меч.
  Вкладка «Меч» появляется, только когда в руке меч.

Мод только на клиенте: косметику видите вы, другие игроки её не видят. Клинок виден от третьего лица (F5) и в меню. В первом лице остаётся обычный меч.

## Как получить jar (без установки Java)
1. Зарегистрируйтесь на github.com и создайте пустой репозиторий (New repository).
2. Загрузите в него все файлы из этого архива вместе с папкой `.github` (Add file → Upload files, перетащите содержимое распакованной папки).
3. Откройте вкладку Actions, дождитесь зелёной галочки у сборки `build`.
4. Откройте сборку, внизу в разделе Artifacts скачайте `Artifacts`, внутри файл `kosmo-cosmetics-1.0.0.jar`.
5. Положите jar в папку `mods` рядом с Fabric API для 1.21.4 и запустите игру на Fabric Loader.

Если сборка упала красным, скопируйте текст ошибки из лога и пришлите его.

## Как собрать на своём компьютере
Нужны JDK и Gradle: `./gradlew build`, результат в `build/libs/`.
